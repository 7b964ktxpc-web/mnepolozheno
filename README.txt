# МНЕ ПОЛОЖЕНО

AI-навигатор по государственным выплатам, пособиям, льготам и законным возможностям.

Текущая рабочая версия: v40.

## Запуск
Статическое приложение: откройте `index.html` или разместите репозиторий на Netlify/GitHub Pages.

## Важно
Приложение выполняет предварительную навигационную проверку. Окончательное решение по выплате принимает официальный орган.

Источник правил хранится в `db.json`. Мониторинг источников находится в `.github/workflows/source-monitor.yml`.

## Архив
`app.html` — архивированный ранний прототип. Текущая версия: `index.html`.
