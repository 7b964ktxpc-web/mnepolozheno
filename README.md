# МНЕ ПОЛОЖЕНО — v40

Персональный навигатор по мерам социальной поддержки. Новосибирская область, 2026.

## Что нового в v40
- автоматический контроль дедлайна ежегодной семейной выплаты;
- динамический индикатор оставшегося времени до 30.09.2026;
- «Пакет подачи» в разделе заявления: автоматически собранные проверки, документы/сведения и последовательность действий;
- пакет учитывает выбранную приоритетную меру и профиль пользователя;
- актуализирована локальная база и лента изменений;
- ИИ-помощник в разделе «Диалог» (Gemini — требует настройки ключа в `localStorage`).

## ИИ-помощник
В разделе «🤖 Диалог» доступен ИИ-помощник на базе Gemini. Для включения:
1. Откройте консоль браузера (F12)
2. Выполните: `localStorage.setItem('mne_gemini_key', 'ВАШ_API_КЛЮЧ')`
3. Перезагрузите страницу
4. В чате появится кнопка «🤖 Спросить ИИ»

ИИ-помощник знает ваш профиль семьи и может ответить на вопросы о мерах поддержки, документах и порядке подачи заявлений.
